# Laptop Price Prediction

Predict laptop prices in euros from hardware and product specifications. This notebook explores the data, builds engineered features, compares regression models, and generates predictions for an unlabeled test set.

## Results

The notebook uses an 80/20 training and validation split (`random_state=42`). These are validation results recorded in the supplied notebook, not scores from the unlabeled test set.

| Model | Validation R² | RMSE (€) | MAE (€) |
| --- | ---: | ---: | ---: |
| Linear regression | 0.883 | 267.36 | 177.63 |
| Ridge, baseline/tuned (`alpha=1`) | 0.892 | 256.66 | 169.13 |
| Lasso | 0.882 | 269.07 | 177.15 |
| Decision tree, baseline | 0.869 | 282.86 | 174.53 |
| Polynomial regression | 0.737 | 401.56 | 268.10 |
| Ridge with log-transformed target (`alpha=0.1`) | **0.910** | **234.99** | **149.59** |

The log-target Ridge experiment has the best reported holdout result. **The final `submission.csv` was generated by a different model:** Ridge with `alpha=0.1` trained on the original price target and all labeled rows, as written in the notebook's final cells. There is no available test-set ground truth or verified Kaggle score here.

## Approach

- **Data:** 881 labeled laptops and 394 unlabeled laptops. The target is `Price (Euro)`; `id` is used only to identify submission rows.
- **Feature engineering:** Extract display pixel density and IPS/touch flags, storage capacities and type flags, CPU family/generation, and simplified product and GPU categories.
- **Preprocessing:** Scale numeric features and one-hot encode categorical features inside scikit-learn pipelines.
- **Evaluation:** Compare linear regression, Ridge, Lasso, decision tree, and polynomial regression using a fixed holdout split and, for most models, five-fold cross-validation on the training portion.
